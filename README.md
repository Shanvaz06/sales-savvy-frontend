# Sales Savvy Frontend

Frontend built using React.js.

## Features
- User Registration
- User Login with JWT
- Product Listing
- Shopping Cart
- Checkout
- Order History
- Admin Dashboard

## Tech Stack
- React.js
- Axios
- React Router
- CSS
